# Grok 工作台样式迁移

界面基于 grok2api v3.1.8 的 `frontend/src/index.css`、`app/app-shell.tsx` 和 `features/creative-console/creative-console-page.tsx` 适配到现有 Next.js 项目；保留 media2api 品牌和现有路由、认证及请求。来源采用 [MIT 许可证](licenses/grok2api-MIT.txt)。

- 黑白灰主题、固定侧边导航、手机抽屉导航；原有管理页面共用基础控件。
- 对话、图片、视频共用创作模式切换和底部输入区。
- 对话支持 Markdown、表格、代码块、复制回复、附件预览/移除、Enter 发送与 Shift+Enter 换行；输入法组合输入不会触发发送。
- 聊天历史从常驻侧栏改为抽屉，仍按用户保存和读取。
- 视频采用卡片画廊、进度显示、播放/下载和提示词复用。
- 号池统一展示 ChatGPT Web、Codex 与 Grok Web，使用“渠道类型”列区分来源，“等级”独立展示套餐；支持统一搜索、渠道/等级/状态筛选及分页。
- 跨页选择、批量同步与删除覆盖所有渠道，删除确认显示各渠道数量；密码恢复仅作用于 ChatGPT / Codex，Grok 保留等级切换、启用/禁用和 SSO 导入。各渠道额度按原始维度展示，不将 Grok 对话/图片/视频额度与 ChatGPT 配额相加。
- Grok 请求失败时保留其他渠道列表，显示错误及重试入口；导入和删除使用弹窗，操作结果通过提示反馈。
- 号池只保留一个“导入账号”入口：在同一弹窗选择 ChatGPT / Codex 或 Grok，再展示对应导入方式；切换平台或取消关闭时清空表单，提交期间禁止切换平台或关闭。

本次只调整前端，不更改 API 合同。前端构建、类型检查、现有测试和浏览器模拟操作验证通过；桌面与 390px 手机宽度验证使用临时隔离服务与合成账号，没有消耗真实上游额度。

统一号池验证：67 项前端测试通过（包含跨渠道标识冲突、组合筛选、状态边界及外部数据校验）；隔离浏览器验证了 12 个合成账号的渠道筛选、搜索空结果、跨页选择、混合删除、导入失败与成功。真实上游额度同步未在本次界面测试中执行。
