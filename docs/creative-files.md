# PPT 与 PSD 创作

管理员登录后，从创作空间进入「PPT 生成」（`/ppt/`）或「PSD 生成」（`/psd/`）。两个页面共用创作导航，支持查看任务进度、历史记录、重命名、清除记录和下载生成文件。

- PPT：填写需求即可生成，也可上传参考图。
- PSD：填写拆分需求并上传图片，生成可编辑 PSD 和图层素材包。
- 从旧 API 调试页迁移后，历史任务、浏览器保存的需求和图片、任务名称及隐藏记录继续保留，无需迁移数据。

API 调试页面及其对话、搜索、Skill 导出界面已移除，旧 `/debug` 地址返回未找到。后端对话、搜索及文件生成接口保持不变；文件任务继续使用 `/v1/ppt/generations`、`/v1/psd/generations` 和 `/v1/editable-file-tasks`。
